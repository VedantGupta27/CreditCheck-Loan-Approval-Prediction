# CreditWise – Loan Approval Prediction

## About the Project
CreditWise is a machine learning project that predicts whether a loan application will be approved based on applicant information.

I developed this project to apply my machine learning knowledge to a practical classification problem and understand how different algorithms perform on loan approval data.

## Algorithms Used
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Gaussian Naive Bayes

## Project Workflow
- Loading and exploring the dataset
- Handling missing values
- Exploratory Data Analysis (EDA)
- Data preprocessing
- Training machine learning models
- Evaluating and comparing model performance

## Technologies Used
- **Language:** Python
- **Environment:** Jupyter Notebook
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

## Dataset
The project uses `loan_approval_data.csv`, which contains applicant-related information for loan approval prediction.

## How to Run
1. Clone or download this repository.
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Open `credit_check.ipynb` in Jupyter Notebook or VS Code.
4. Run the notebook cells in order.
